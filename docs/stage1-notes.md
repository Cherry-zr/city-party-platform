# Stage 1 Notes

第一阶段目标是完成核心业务最小闭环，不一次性实现最终全部功能。

## Implemented

- Auth, JWT, Redis captcha
- User profile and public user page
- Local avatar and activity cover upload
- Activity publish, list, detail
- Signup, cancel, creator approval
- Favorite and my favorites
- Mobile H5 pages
- Admin dashboard, users, activities, signups, credits, reports
- MySQL schema and seed data
- Knife4j API documentation

## Reserved

- AMap integration
- WebSocket chat
- Signup waiting queue
- Full credit score rules
- AA bill payment confirmation
- Partner recommendation
- Notice read/unread and real-time push
- Review flow
- Report processing flow
