# 简历项目描述

## 一句话介绍

同城活动发现与陌生人组局平台是一个基于 Vue3、Spring Boot、MySQL 和 Redis 的全栈项目，支持活动发布、报名候补、群聊通知、评价信用、后台管理和运营数据看板。

## 项目经历描述

- 设计并实现同城活动核心闭环，包括活动发布、列表筛选、地图附近活动、报名审核、退出报名、候补队列和候补转正。
- 使用 Spring Boot、MyBatis-Plus 和 MySQL 构建后端业务模块，通过数据库唯一约束和条件更新减少重复报名与并发超员问题。
- 实现 JWT 鉴权、数据库角色复核、PBKDF2 密码存储、WebSocket 握手鉴权和文件上传内容校验，提高基础安全性。
- 搭建管理员后台和运营数据看板，定义用户、活动、报名、评价、信用、评分、热门活动等指标口径，并通过 ECharts 完成可视化。
- 补充 Docker MySQL / Redis 开发环境、演示数据脚本、后端单元测试、Playwright 冒烟测试、GitHub Actions CI 和 Gitleaks 安全扫描。

## 技术难点

### 报名并发和重复报名

同一活动同一用户通过 `activity_signup(activity_id,user_id)` 唯一约束防重复；名额占用通过数据库条件更新 `approved_count < max_participants` 控制，避免只依赖内存判断。

### 候补转正一致性

Redis List 维护候补顺序，MySQL 保存最终状态；Redis 不可用时可以回退查询 MySQL 的 `WAITING` 记录，保证业务状态可追踪。

### 旧 JWT 权限失效

JWT 中虽然携带角色，但 HTTP 拦截器和 WebSocket 握手都会重新查询数据库，用户被禁用或角色被移除后旧 token 不能继续访问。

### 数据看板口径

为每个指标明确时间字段、包含状态、排除状态、空数据和除零处理，避免统计 SQL 与业务含义不一致。

## 2 分钟介绍

这个项目是一个完整的全栈简历项目，业务场景是同城活动发现和陌生人组局。用户端支持注册登录、活动列表、地图附近活动、发布活动、报名、候补、收藏、群聊、评价和信用分；管理员端支持用户、活动、报名、评价、信用、通知等基础查询，并提供数据看板。

技术上，前端采用 Vue3、Vite、Pinia、Vue Router、Vant、Element Plus 和 ECharts；后端采用 Java 17、Spring Boot 3、MyBatis-Plus、MySQL、Redis、JWT 和 WebSocket。数据库设计包含用户、活动、报名、候补、群聊、评价、信用、通知等 18 张业务表。

我在项目中重点解决了几个实际开发问题。第一是报名并发和重复报名：通过数据库唯一约束防止同一用户重复报名，通过条件更新控制活动名额，减少并发超员。第二是候补转正：Redis List 维护候补顺序，MySQL 保存最终状态，Redis 异常时可以回退数据库。第三是权限安全：JWT 只作为身份凭证，后端每次都会复核数据库中的用户状态和角色，避免禁用用户或角色变更后旧 token 继续生效。第四是数据看板：为每个指标明确时间字段、状态范围、空数据和除零处理，只缓存首页概览，详细分析实时查询数据库。

工程化方面，我补充了项目专用 Docker MySQL 和 Redis 环境、可重复导入和清理的演示数据、85 个后端测试、2 个 Playwright 冒烟测试、GitHub Actions CI 和 Gitleaks 安全扫描。这个项目定位是一个功能完整、可运行、可演示、适合面试讲解的全栈项目。
